# Sonsuz Kahve Demleme Makinesi

## Bu Repo Nedir?

Bu depo, insanlığın en büyük sorusuna cevap arar: "Kahve ne zaman demlenecek?"

Cevap: **ASLA.**

Bilimsel araştırmalar göstermiştir ki, bu simülatör çalıştırıldığında kahve demleme süreci başlar ve evrenin ısı ölümüne kadar devam eder. Bu, modern fizik ve termodinamik yasalarına tamamen uygundur.

## Kurulum

```bash
pip install time
python kahve_demleyici.py
```

(Not: `time` zaten Python'un içinde. Biz abartmayı seviyoruz.)

## Kullanım

Scripti çalıştırın. Terminaliniz sonsuza dek kahve demleme loglarıyla dolacak. Bu bir bug değil, bir özelliktir.

Ctrl+C ile durdurabilirsiniz ama kahve hala demlenmeye devam eder. Çünkü gerçek hayatta da böyledir.

## Bilimsel Arka Plan

Bu proje, "Sonsuz Bekleme Teorisi" üzerine kuruludur. Teorinin temel ilkesi: Eğer bir şey yeterince uzun sürerse, o şey artık zaman kavramından bağımsız hale gelir.

Kaynaklar:
- Termodinamik 2. Yasası
- Küçük Prens (kahve içen versiyonu)
- Amcamın "Kahve bitti mi?" diye sorduğu anlar
